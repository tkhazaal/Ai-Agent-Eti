# Answer Patterns

Reusable, approved responses for recurring DMs, comments, emails, and questions. Search here before drafting a reply to a new message; reuse the approved logic and wording, but adjust for the current person and context. Never blindly copy if conditions differ.

- **Related:** [Communication style](../rules-and-preferences/communication-style.md), [Support & escalation](../rules-and-preferences/support-and-escalation.md), [Issue log](issue-log.md)

## How to add a pattern

```
### AP-nn — <question / issue / pattern>
- Affects: <who> / context:
- Previously replied or decided:
- Approved response / draft / resolution steps:
- Exceptions, eligibility rules, links, escalation conditions:
- Outcome (if known):
- Source examples:
- Date last used:
- Status: confirmed / pending / needs verification
```
