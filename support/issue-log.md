# Support Issue Log

Structured log for complaints, cancellations, refunds, billing concerns, and access problems.

- **Maintained by:** Carolina · **Related:** [Support & escalation](../rules-and-preferences/support-and-escalation.md), [Answer patterns](answer-patterns.md)
- **Privacy:** never expose one customer's details in another customer's reply. One entry per person-issue.

## How to add an entry

Copy the template below, fill what is known, mark unknowns as `needs confirmation`. Give each entry a stable ID (`ISS-YYYYMMDD-nn`).

```
### ISS-YYYYMMDD-nn — <short title>
- Person: <name / handle> (contact: <email>)
- Issue type: complaint / cancellation / refund / billing / access
- Product / order: <product name, order confirmation>
- Date raised:
- Source: DM / email / FB comment / IG / other
- Communication history: <dated bullets>
- Status: open / awaiting-customer / escalated / resolved
- Owner:
- Resolution:
- Next action + due:
- Related: <links to answer-pattern / client note / link registry>
```
